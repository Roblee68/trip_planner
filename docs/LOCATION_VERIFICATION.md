# Location verification

Along requires a lookup and explicit selection of a geographic destination. The server checks the caller's confirmation receipt, exact selected label and seven-day expiry before reserving a paid AI action. Editing the input invalidates confirmation. Photon/OpenStreetMap handles worldwide cities, towns, addresses and landmarks; coordinate input is range-checked. Coverage depends on OSM; no matches means no paid route search.

Lookup is an explicit button, never keystroke autocomplete. Private per-account caches last seven days, with 20 uncached lookups/account/day, 300 globally/day and a shared 1.1-second provider throttle. Photon public service has no availability guarantee; configure PBB_GEOCODER_BASE_URL to a hosted/private HTTPS instance before exceeding modest usage. Provider failures show a retry message and use no AI allowance.

Foreground GPS requires OS permission and the user's Use my current location selection. Permission is checked again before transmission. Precise fixes stay in memory, expire after 15 minutes, and are cleared on manual-place selection, denied permission or failed refresh. Searches transmit coordinates rounded to three decimal places (roughly 100 metres), only for the matching selected place. No background location permission or location-history collection is used. Device timezone comes from the OS; events retain their own IANA timezone. Reverse geocoding uses the phone's platform service.

Firebase callable requests use HTTPS and require authenticated accounts or guest sessions. Firestore denies direct client access to all collections. The shared catalogue contains public event locations, not users' GPS fixes. Private route cache IDs hash the request and user ID; raw request coordinates are not stored. Route responses can contain origin/destination text and remain private to the caller; account deletion removes private caches. OpenAI receives the approximate approved origin for route research with response storage disabled. Destination lookup sends only the entered destination text to Photon. No GPS payloads are deliberately logged.
